# Автопостинг статей Грантовика: сайт → Дзен + VC.ru

## Как это работает

1. Статья — markdown-файл в `content/articles/` с датой публикации.
2. Каждый день в 08:00 МСК GitHub Actions собирает блог (`/blog/`), обложки и RSS-ленту `/rss/dzen.xml`, после чего коммитит результат → Vercel деплоит сайт.
3. **Дзен** сам забирает RSS и публикует статьи на канале. Ничего делать не нужно.
4. **VC.ru**: у VC нет публичного API для публикации, поэтому на каждую новую статью создаётся GitHub Issue с готовым текстом под VC: открыть → скопировать → вставить → опубликовать (около 2 минут). Публикуйте на VC не больше 1 статьи в день.
5. По понедельникам Claude пишет 3 новые статьи из очереди `data/topics.json` и открывает Pull Request. Статья выходит только после вашего мёржа, в дату из файла (раз в 2 дня).

## Установка (один раз, ~15 минут)

1. Скопируйте содержимое архива в корень репозитория `Unogaev/grantovik` и запушьте в `main`.
2. GitHub → Settings → Actions → General:
   - Workflow permissions → **Read and write permissions**;
   - галочка **Allow GitHub Actions to create and approve pull requests**.
3. GitHub → Settings → Secrets and variables → Actions → New secret: `ANTHROPIC_API_KEY` (ключ можно взять у Артёма или в console.anthropic.com). Без ключа работает всё, кроме автогенерации.
4. Actions → «Автопостинг статей» → **Run workflow** — первый прогон создаст 11 задач на VC.
5. Проверьте, что открываются https://grantovik.ru/blog/ и https://grantovik.ru/rss/dzen.xml.
6. В `robots.txt` сайта не должно быть запрета на `/rss/` и `/blog/`. Добавьте строку `Sitemap: https://grantovik.ru/blog/sitemap.xml`.

## Подключение RSS в Дзене

1. Студия Дзена → Настройки канала → «Сайт»/«RSS» (раздел объединения сайта и канала).
2. Подтвердите права на grantovik.ru (Дзен предложит метатег или файл — метатег вставить в `<head>` главной страницы).
3. Укажите ленту: `https://grantovik.ru/rss/dzen.xml`.

Требования Дзена: в ленте минимум 10 материалов при первом подключении (сейчас 11) и не меньше 3 публикаций на сайте за последний месяц (выполняется при графике раз в 2 дня).

Если хотите сначала проверять каждую статью в Дзене вручную, задайте в репозитории переменную `DZEN_MODE=draft` — статьи будут приходить в черновики Студии. Для этого в шаге «Сборка блога» workflow добавьте `env: DZEN_MODE: draft`.

## Как добавить статью вручную

Создайте файл `content/articles/2026-10-10-moya-statya.md`:

```
---
title: Заголовок статьи
slug: moya-statya
date: 2026-10-10 09:00
description: Описание для карточки и поиска
tags: АПК, фермерам
vc_title: Альтернативный заголовок для VC
vc_lead: Лид для VC в 2–3 предложения
---
Текст. Разделы через "## ", списки через "- ", ссылки [текст](url).

{{CTA}}

Продолжение текста.
```

`{{CTA}}` — блок «Проверить по ИНН» со ссылкой на сайт (в Дзене и VC — с UTM-метками, чтобы видеть трафик в Метрике).
Темы для автогенерации — в `data/topics.json`, просто дописывайте новые строки.

## Локальный запуск

```
python3 scripts/make-cover.py     # обложки (нужен pip install pillow)
node scripts/build-blog.mjs       # сборка
ANTHROPIC_API_KEY=... node scripts/generate-article.mjs 2   # 2 новые статьи
```
